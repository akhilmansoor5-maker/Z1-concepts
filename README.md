# Z1 Concepts

Website for **Z1 Concepts**, an automotive detailing, protection and styling studio in Manjeri, Kerala.

## Pages

- `/` Homepage
- `/services` Detailing
- `/protection` PPF and coatings
- `/styling` Wrapping, body kits and related styling
- `/gallery` Studio photographs
- `/about` Studio
- `/contact` Address, phone, WhatsApp and Google reviews

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
